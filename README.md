# Разработка консольного Java-приложения для агрегации данных из нескольких открытых REST API
## Основные функции
- Получение данных из трех и более различных REST API по HTTP;
- Сохранение агрегированных данных в файл заданного формата и чтение из него;
- Выполнение опроса источников параллельно, с контролем количества одновременно выполняемых задач и интервалов между запросами.

## Режимы работы
1. Автоматический – принимает на вход набор параметров
   - Список используемых API,
   - Формат выходного файла: JSON или CSV,
   - Максимальное количество одновременно выполняемых задач,
   - Интервал опроса источников,
   - Количество опросов, которое должно быть выполнено для каждого источника.
2. Интерактивный – параметры задаются с помощью пользовательского ввода
   - Выбор API для опроса из предложенного списка,
   - Задание формата выходного файла: JSON или CSV, 
   - Выбор режима работы с выходным файлом: создание нового или добавление в существующий, 
   - Выбор API для вывода на экран: все предложенные или какое-либо конкретное, 
   - Максимальное количество одновременно выполняемых задач,
   - Интервал опроса источников.

## Требования к реализации
- **ООП**: приложение должно быть реализовано с использование принципов ООП;
- **Масштабирование**: архитектура приложения должна позволять добавление нового API без изменения основной логики приложения;
- **Разделение ответственности**: логика пользовательского ввода, получения, обработки, сохранения данных и управления потоками должна быть разделена по ответственности;
- **Интервал опроса**: повторный опрос одного и того же API должен происходить не чаще, чем через заданный интервал после завершения предыдущего запроса;
- **Безопасность**: все операции должны быть потокобезопасными, ресурсы должны освобождаться корректно;
- **Тестирование**: бизнес-логика приложения должна быть покрыта Unit-тестами не менее, чем на 70%;
- **Сборка**: приложение должно собираться с использованием Maven.

## Используемые инструменты
- Сетевая часть: `java.net.http`
  - `HttpClient`, `HttpRequest`, `HttpResponse`
- Парсинг данных: `com.fasterxml.jackson` 
  - `core`, `databind`, `dataformat.csv`
- Параллелизация: `java.util.concurrent` 
  - `locks`, `atomic`, `ScheduledExecutorService`, `Future`
- Временные интервалы: `java.time` 
  - `Duration`, `LocalDateTime`

## Используемые API
- **“The One Api to rule them all”**: информация о вселенной The Lord of the Rings. В качестве endpoint-а была выбрана страница с персонажами
  - Допустимые query параметры
    - Id 
    - Quote 
    - Name 
    - Race и др.
  - https://the-one-api.dev/v2/character

- **“The Owen Wilson Wow Api”**: информация о Wow актера Оуэна Уилсона. В качестве endpoint-а была выбран адрес для получения случайного Wow в формате JSON
  - Query параметры не предусмотрены
  - https://owen-wilson-wow-api.onrender.com/wows/random/

- **“Sunset and Sunrise Times Api”**: информация о времени восхода и заката в заданных координатах. В качестве значения по умолчанию выбраны координаты Главного здания Санкт-Петербургского Политехнического университета.
  - Допустимые query параметры
    - Latitude
    - Longitude
  - https://api.sunrise-sunset.org/json?lat=60.007420&lng=30.372698
